# منصة التعلم التكيفي الذكي للشبكات (NetLearn Pro)
> **المنصة الذكية المتقدمة والمتخصصة في تدريب وتأهيل مهندسي الشبكات وفق معايير Cisco CCNA العالمية**

---

## 📌 1. نظرة عامة على المشروع
**NetLearn Pro** هي منصة تعليمية وتطبيقية تفاعلية قائمة على خوارزميات التعلم التكيفي (Adaptive Learning). صُممت لتمكين الطلاب ومهندسي الشبكات من استيعاب المفاهيم الهندسية الأساسية والمتقدمة وفق معايير **Cisco CCNA**، واختبار مستوياتهم تشخيصياً، والتطبيق العملي في مختبر حي لحسابات وتجزئة الشبكات الفرعية (IPv4 Subnetting).

---

## 🚀 2. متطلبات وبيئة التشغيل (Installation & Setup)
* **نظام التشغيل:** Windows (WAMP64 أو XAMPP) أو Linux (LAMP).
* **خادم الويب:** Apache 2.4+.
* **بيئة التشغيل:** PHP 7.4+ (متوافق حتى PHP 8.2+).
* **قاعدة البيانات:** MySQL 5.7+ أو MariaDB 10.4+.

### خطوات التثبيت السريع:
1. تأكد من تشغيل خادمي Apache و MySQL في **WAMP** أو **XAMPP**.
2. مسار المشروع داخل المجلد الافتراضي:
   ```text
   C:\wamp64\www\network_learning\
   ```
3. **تهيئة قاعدة البيانات:**
   * يتم استيراد وإنشاء قاعدة البيانات تلقائياً عند أول زيارة للمنصة عبر السكربت الذكي في `config/db.php`.
   * أو يمكنك استيراد ملف `database.sql` يدوياً عبر **phpMyAdmin**:
     * اسم قاعدة البيانات: `network_adaptive_db`
     * الترميز الموصى به: `utf8mb4_unicode_ci`
4. افتح المتصفح وتوجه إلى:
   ```text
   http://localhost/network_learning/
   ```

## 🏗️ 5. المخطط العلائقي لقاعدة البيانات (Data Schema)
* **`levels`**: المستويات الأربعة للمسار التعليمي.
* **`topics`**: موضوعات المنهج التخصصية (16 موضوعاً).
* **`study_modules`**: الدروس المدمجة المعمارية (بما فيها نموذج OSI الكامل بالطبقات السبع).
* **`questions`**: بنك الأسئلة المتدرج بالصعوبة والتفسير الهندسي.
* **`exam_attempts`**: سجل المحاولات المستقل وتوقيت البداية والنهاية والنتيجة.
* **`attempt_questions`**: الأسئلة المخصصة لكل محاولة وإجابة الطالب عليها.
* **`exam_results`**: النتائج المعتمدة لسرعة العرض في اللوحات.
* **`lab_attempts`**: نتائج محاولات مختبر Subnetting التفاعلي.
* **`learning_progress`**: تتبع قراءة وإتمام الدروس الأكاديمية.

## 🎯 6. جاهزية العرض أمام لجنة المناقشة (Graduation Presentation)
1. **استعراض الصفحة الرئيسية والواجهة الفاتحة الأكاديمية:** إظهار التنسيق الرصين، وغياب الألوان النيونية أو الإيموجي العشوائي، ودعم RTL المحكم.
2. **المختبر التفاعلي (Subnet Simulator):** إدخال عنوان IPv4 وبادئة CIDR، استعراض تمثيل الـ 32 بت الثنائي، وتجربة الحالات الخاصة (`/30`, `/31`, `/32`).
3. **الاختبار التشخيصي (Diagnostic Placement):** إظهار دقة احتساب الأسئلة المفقودة وخوارزمية الفرز للمستوى الأنسب.
4. **التغذية الراجعة التفسيرية (Explanatory Feedback):** خوض اختبار وإظهار تفسيرات الإجابات الصحيحة والخاطئة للجنة.
5. **لوحة المشرف والتحليلات:** استعراض توزيع الطلاب، ومعدلات الاجتياز عبر Chart.js، وإدارة الأسئلة بأمان.
